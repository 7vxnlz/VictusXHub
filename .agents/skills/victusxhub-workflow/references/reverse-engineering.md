# Reverse Engineering

Read `docs/development/REFERENCE_POLICY.md` and `docs/reference-index.md` before reference research.

1. Start with static evidence; identify the semantic method, then trace transport and serialization.
2. Separate copied/common ancestry from independent evidence, and generic-family evidence from exact-device evidence.
3. Classify confidence explicitly. Do not make active hardware requests without separate authorization.
4. Extract protocol facts only; do not copy proprietary implementation, UI, or assets.
